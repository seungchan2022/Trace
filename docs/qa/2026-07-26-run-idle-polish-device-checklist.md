# 러닝 대기 화면 실기기 체크리스트 (2026-07-26)

> 이번 변경은 러닝 탭을 `오늘의 러닝 → 목표 선택 → 시작` 순서로 정리했습니다. 실제로 뛰지 않아도 됩니다. 기기를 케이블로 연결한 채 Xcode에서 앱을 실행하고, `Debug` → `Simulate Location`에서 [5km·1분 페이스 GPX 파일](trace-history-tab-5km-1min-pace.gpx)을 선택하면 위치가 이동하는 것처럼 확인할 수 있습니다. 파일은 5분 동안 5km를 이동한 뒤 30초 동안 멈추므로, 끝나기 전에 러닝을 종료해 주세요.

## 빌드/설치

- [ ] 이 브랜치의 앱을 실기기에 설치하고 실행했다.
- [ ] 위치 권한이 허용되어 있다. 이미 허용했다면 그대로 진행한다.

## 세션 1: 오늘의 러닝을 정하고 시작하기

**준비:** 러닝 탭을 처음 연 상태.

**수행:**

1. `오늘의 러닝` 아래에서 `자유`, `거리`, `시간`을 차례로 눌러 본다.
2. `거리`를 고른 뒤 숫자와 `km`가 보이는지 확인하고, 원하는 값을 한 번 바꿔 본다.
3. `시간`도 고른 뒤 분 단위 입력이 보이는지 확인한다.
4. 기기 글자 크기를 한 단계 이상 크게 하고, 어두운 화면에서도 같은 화면을 연다.

**확인할 것:**

- 첫 화면에서 무엇을 고르고 어디를 누르면 시작하는지 바로 이해된다.
- 지난 러닝이나 이번 주 기록을 이 화면에서 찾게 되지 않고, 필요하면 `기록` 탭에서 본다는 구분도 자연스럽다.
- 자유를 고르면 추가 입력이 없고, 거리·시간을 고르면 알맞은 입력과 단위가 보인다.
- `오늘의 러닝`, 목표 선택, 입력 카드, `시작` 버튼이 겹치거나 잘리지 않는다.
- 어두운 화면에서도 제목·선택한 목표·시작 버튼이 읽기 쉽다.

## 세션 2: 목표를 정해 GPX 러닝을 저장하고 기록에서 확인하기

**준비:** Xcode에서 위 GPX 파일을 선택할 수 있는 상태. 파일이 끝나기 전 종료할 수 있게 30초 이상 남겨 둔다.

**수행:**

1. 러닝 탭에서 거리 또는 시간 목표를 하나 고르고 값을 확인한 뒤 `시작`을 누른다.
2. 카운트다운이 끝난 뒤 Xcode에서 GPX 위치 시뮬레이션을 시작한다.
3. 거리가 조금 증가한 것을 확인하고, 일시정지한 뒤 종료를 길게 눌러 저장이 끝날 때까지 기다린다.
4. 러닝 탭으로 돌아왔을 때 이전 러닝·이번 주 기록 같은 문구가 새로 나타나지 않는지 확인한다.
5. `기록` 탭을 열어 방금 저장한 러닝이 맨 위에 있는지 확인한다.

**확인할 것:**

- 목표를 정한 뒤 시작 행동이 자연스럽게 이어진다.
- 저장 뒤 러닝 탭의 대기 화면은 `오늘의 러닝`, 목표, `시작` 흐름 그대로다.
- 방금 저장한 기록은 기록 탭에서 거리와 날짜가 맞게 보인다.

**결과:** ☐ 통과 ☐ 실패
