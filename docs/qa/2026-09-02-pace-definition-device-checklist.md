# 페이스 두 지표 표시 실기기 체크리스트 (2026-09-02)

> 이제 러닝 화면과 잠금화면 모두에 페이스가 **"현재 페이스"와 "평균 페이스" 두 개**로 나뉘어
> 보입니다. "현재 페이스"는 최근 몇 초 동안의 속도만 반영해서 지금 얼마나 빠른지를 빠르게
> 보여주고, "평균 페이스"는 지금까지 뛴 전체 평균이라 1킬로미터마다 나오는 음성 안내가
> 말하는 숫자와 같습니다. 예전에는 "페이스" 하나만 있어서 두 값이 섞여 보였는데, 이제는
> 라벨로 구분됩니다.
>
> 이 중에서도 "실제로 뛰면서 잠금화면·Dynamic Island가 좁은 화면에서 두 값을 안 겹치게
> 보여주는지", "잠깐 신호를 기다리는 것처럼 멈춰 서 있을 때도 값이 이상하게 보이지 않는지"는
> 시뮬레이터로는 확인이 어려워서, 아래 항목들을 실제 기기에서 봐주시면 좋겠습니다.

빌드/테스트는 전부 통과했습니다(자동 테스트 388개 전체 통과, 회귀 없음). 시뮬레이터에서도
화면 배치와 값이 서로 다르게 갱신되는 것까지는 확인했지만, 실제 화면 크기·잠금화면 카드·
Dynamic Island 동작은 실제 기기에서만 확인할 수 있습니다.

**사용법:** 아래 세션 1, 2를 순서대로 진행합니다(하나의 러닝으로 이어서 하면 됩니다). 수행 후
실제로 본 결과가 기대와 같으면 통과에 체크, 다르면 실패에 체크하고 메모에 무슨 일이
일어났는지 짧게 적어주세요.

## 핵심 기능 (손으로 수행)

### 세션 1: 러닝 화면에서 두 페이스 확인

**준비:** 러닝 탭에서 위치 권한을 이미 허용한 상태.

**수행:**
1. "시작" 버튼을 눌러 러닝을 시작한다.
2. 화면을 켠 채로 30초~1분 정도 걷거나 뛴다.
3. 화면 아래쪽 보조 숫자 줄(시간·평균 페이스·현재 페이스)을 본다.
4. 속도를 확 바꿔본다 — 몇 초간 빠르게 뛰다가 다시 천천히 걷는다.

**확인할 것 1:** 시간·평균 페이스·현재 페이스 세 숫자와 라벨이 잘리거나 겹치지 않고 다
보여야 한다.

**결과:** ☐ 통과 ☐ 실패
**메모:**

**확인할 것 2:** 속도를 바꾸면 "현재 페이스"는 금방 따라 바뀌고, "평균 페이스"는 천천히
바뀌어야 한다(전체 평균이라 한 번에 크게 안 움직이는 게 정상). 두 숫자가 눈이 어지러울
정도로 자주 깜빡이듯 바뀌면 실패.

**결과:** ☐ 통과 ☐ 실패

### 세션 2: 잠금화면·Dynamic Island에서 두 페이스 확인 (세션 1에 이어서)

**준비:** 세션 1에서 시작한 러닝을 계속 진행 중인 상태.

**수행:**
1. 전원 버튼을 눌러 화면을 잠그고 잠금화면 카드를 본다.
2. 화면 잠금 상태에서 30초 이상 더 걷거나 뛴다.
3. 일시정지 버튼을 눌러 몇 초간 멈춘 뒤, 다시 잠금화면 카드를 본다.
4. 재개 버튼을 누르고 계속 걷거나 뛰어 1킬로미터를 채운다(1킬로미터 음성 안내가 나온다).
5. 안내가 끝난 직후 바로 잠금화면 카드를 본다.
6. Dynamic Island(화면 위쪽 알약 모양 영역)를 길게 눌러 확장된 상태로 본다.

**확인할 것 1:** 걷는 중(정지하지 않은 상태)에 잠금화면 카드의 숫자·라벨(현재 페이스, 평균
페이스 포함)이 잘리거나 겹치지 않고 다 보여야 한다.

**결과:** ☐ 통과 ☐ 실패
**메모:**

**확인할 것 2:** 일시정지한 뒤 본 잠금화면도 마찬가지로 숫자·라벨이 잘리거나 겹치지 않아야
한다(멈춘 시간 표시가 길어지는 순간이라 특히 좁아 보일 수 있는 지점입니다).

**결과:** ☐ 통과 ☐ 실패
**메모:**

**확인할 것 3:** 1킬로미터 음성 안내가 말한 숫자와, 그 직후 잠금화면에 보이는 "평균 페이스"
숫자가 같아야 한다. "현재 페이스"는 그 숫자와 달라도 정상이다(오작동이 아니다) — 다만 두
숫자가 라벨 없이 뒤섞여 보이면 안 되고, 어느 게 현재이고 어느 게 평균인지 라벨로 분명히
구분돼야 한다.

**결과:** ☐ 통과 ☐ 실패
**메모:**

**확인할 것 4:** Dynamic Island를 길게 눌러 확장했을 때, 그 안에서도 현재 페이스·평균
페이스 숫자와 라벨이 실제로 보여야 한다(빈 화면이거나 아무것도 안 뜨면 실패 — 지금까지
시뮬레이터에서는 이 확장된 화면이 비어 보이는 문제가 있어서, 실기기에서도 같은지 특히
확인이 필요합니다).

**결과:** ☐ 통과 ☐ 실패
**메모:**

## 의도 일치
- [ ] "현재 페이스"·"평균 페이스" 라벨과 배치가 자연스럽게 읽히는지(어느 게 어느 값인지
      헷갈리지 않는지)
- [ ] 현재 페이스가 반응하는 속도가 실제 체감과 맞는지(너무 굼뜨거나, 너무 민감하지 않은지)

## 알려진 한계 (버그 아님)
- [ ] 신호를 기다리는 것처럼 완전히 멈춰 서 있는데 일시정지 버튼은 안 누른 채로 오래
      있으면, 평균 페이스 숫자가 잠깐 그 자리에 멈춰 있다가 다시 걷기 시작하면 정상으로
      돌아오는 경우가 있을 수 있습니다(이미 알려진 것이며 이번 작업 범위 밖입니다). 이런
      경우를 실제로 보셨다면 어떤 상황이었는지 메모에 적어주시면 좋습니다.
