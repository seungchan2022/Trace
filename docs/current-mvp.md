> 사용자용 진행 현황판이다. 구현 정본은 spec·plan·roadmap이며, 내용이 충돌하면 구현 정본을 따른다.

## 현재 상태

**진행 중인 MVP도, 진행 중인 독립 사이클도 없다.**

마지막으로 끝낸 것은 MVP 밖 독립 사이클 `pace-definition`(2026-09-03 완료)이다. 이제 트래킹
화면과 잠금화면 모두에서 「현재 페이스」와 「평균 페이스」가 라벨로 구분돼 나란히 보이고, 현재
페이스는 최근 10초를 기준으로 삼는다. 1km 발화와 잠금화면의 숫자가 달라 오작동으로 읽히던
문제가 이것으로 해소됐다.

- **남은 확인 하나**: 10초로 줄인 창이 실제로 달릴 때 읽기 편한지는 아직 재지 못했다. QA를 등속
  GPX 재생으로 진행해서 현재 페이스 칸이 계속 비어 있었기 때문이다. 실제로 달려 보셨을 때
  숫자가 너무 자주 튀면 알려 주시면 창 값을 다시 조정한다([백로그](backlog.md)에 항목으로 있다).
- **바로 착수할 수 있는 다음 것**: 독립 사이클 `pace-dedup`(정비) — 평균 페이스 계산식이 네 곳에
  복사된 것과 앱·위젯 페이스 포맷터 이중 구현을 한자리로 모은다. 사용자가 새로 할 수 있게 되는
  일은 없고, 앞으로 페이스 기준을 바꿀 때 한 곳만 고치면 되게 만드는 작업이다.

다음에 무엇을 할지는 정해져 있지 않다. `pace-dedup`으로 이어 가도 되고, [백로그](backlog.md)의
다른 축(코스 편집 UX·지도 렌더링)이나 새 기능으로 가도 된다.
