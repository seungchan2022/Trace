# 현재 MVP 현황판

> 사용자용 진행 현황판이다. 구현 정본은 spec·plan·roadmap이며, 내용이 충돌하면 구현 정본을 따른다.

## 현재 상태

**진행 중: MVP 밖 독립 사이클 `pace-dedup`(작은 기능) — 문서 완료, 다음 세션에서 구현 시작.**

페이스를 계산하는 같은 식이 코드 일곱 자리에 흩어져 있는 것을 한 곳으로 모으는 작업이다.
화면에 새로 생기는 것은 없고, **한 경우에만 표시가 달라진다** — 위치 권한이 회수돼 러닝이 끊기면
지금은 요약 화면의 시간이 다른 기준으로 나오고 평균 페이스가 비어 있는데, 그것이 정상 종료했을
때와 같아진다.

- **결정하신 것 (2026-09-03)**
  - 착수 순서는 이미 정한 대로 이 작업을 계속한다 — 코스 편집·지도 축으로 건너뛰지 않는다.
  - 정비에서 **작은 기능으로 승격**한다. 실측에서 범위가 넓어졌고 동작 변화가 하나 생겼다.
  - 위 권한 회수 경로의 표시 변경을 그대로 진행한다.
- **지금 확인하실 것은 없다.** 설계와 구현 계획을 승인받아 문서가 끝났고, 다음 세션이
  [구현 계획](superpowers/plans/2026-09-03-pace-dedup.md)의 Task 1부터 시작한다.
- **끝나면 알려 드릴 것**: 잠금화면에 페이스가 이전과 같게 보이는지는 자동 검증으로 덮이지
  않는다. 다음에 실제로 달려 보실 때 확인해 주셔야 하는 몫이다.

### `pace-definition`(2026-09-03 완료)에서 남은 확인 하나

10초로 줄인 현재 페이스 창이 실제로 달릴 때 읽기 편한지는 아직 재지 못했다. QA를 등속 GPX
재생으로 진행해서 현재 페이스 칸이 계속 비어 있었기 때문이다. 실제로 달려 보셨을 때 숫자가 너무
자주 튀면 알려 주시면 창 값을 다시 조정한다([백로그](backlog.md)에 항목으로 있다).
