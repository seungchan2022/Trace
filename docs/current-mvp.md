# 현재 MVP 현황판

> 사용자용 진행 현황판이다. 구현 정본은 spec·plan·roadmap이며, 내용이 충돌하면 구현 정본을 따른다.

## 현재 상태

**진행 중인 MVP·사이클 없음.**

마지막으로 끝난 것은 MVP 밖 독립 사이클 `pace-dedup`(작은 기능, 2026-09-03 완료)이다. 페이스를
계산하는 같은 식이 코드 일곱 자리에 흩어져 있던 것을 한 곳으로 모았고, 페이스 표기 규칙도 앱과
위젯 타깃이 공유하게 했다. **한 경우에만 표시가 달라졌다** — 위치 권한이 회수돼 러닝이 끊긴
경우, 요약 화면의 시간이 이제 정상 종료했을 때와 같은 기준으로 나오고 평균 페이스도 채워진다.
결과 상세는 [로드맵의 완료 기록](roadmap.md#완료--mvp-밖-독립-사이클)을 참고.

- **지금 확인하실 것은 없다.** 구현·리뷰·문서 정리가 모두 끝났고, 통합 방식(머지/PR)만
  다음으로 결정하면 된다.
- 잠금화면 페이스 표시가 이전과 같은지 확인은 종료 조건으로 걸지 않고
  [백로그](backlog.md)의 「pace-definition (2026-09-03) 실기기 QA 피드백」 절에 실주행 확인
  항목으로 넘겼다 — 실제로 달리실 때 눈에 걸리면 알려 주시면 된다.
